Bioscope Google Map Block
Version: 1.0.0

FEATURES
- Gutenberg block: Google Map
- Live iframe preview in the editor
- Location/address search embed without an API key
- Optional Google Maps URL override
- Adjustable width (e.g. 100%, 800px)
- Adjustable height (150-1200px)
- Zoom and corner radius controls
- Responsive max-width handling
- Accessible iframe title and lazy loading

INSTALLATION
1. In WordPress Admin, go to Plugins > Add New Plugin > Upload Plugin.
2. Upload bioscope-google-map-block.zip and activate it.
3. Edit a page/post and insert the “Google Map” block.
4. Enter a location or paste a Google Maps embed URL, then adjust the size in the block settings.

NOTES
- This uses Google's public Maps search embed URL and does not require an API key for the location-search mode.
- Google Maps must be reachable from the editor browser for the live preview to load.
- Some pasted Google Maps share URLs may not be embeddable. Prefer the iframe src URL from Google Maps' Share > Embed a map option.
